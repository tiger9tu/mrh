# Experimental LAS-LUSCC

This package implements linearized unitary coupled cluster in a LASSI model
space. It accepts either a LAS reference or a post-kernel LASSI reference and
constructs selected product states for the standard LASSI solver.

```python
from mrh.exploratory.luscc import LUSCC, get_grad_exact

gradients, selected, a_idxs, i_idxs = get_grad_exact(las)
energy, si = LUSCC(las, a_idxs, i_idxs).kernel()
```

Spin targeting is opt-in and uses the physical spin quantum number `S`:

```python
energy, coefficients, s2, residual = LUSCC(
    las, a_idxs, i_idxs, target_spin=0
).kernel()
```

LUSCC fragment vectors need not be spin pure. Consequently this path does not
use the LASSI Clebsch--Gordan basis. It applies fragment `S^2`, `S+`, and `S-`
operators directly to each fragment CI vector and factorizes overlaps of the
resulting product-state terms. The numerical null space of the residual Gram
matrix `<Q psi_i|Q psi_j>`, rather than a compressed `S^2` matrix, defines the
exact target-spin subspace. The constrained Hamiltonian is then solved by the
same matrix-free LASSI Davidson engine used for large ordinary LASSI spaces.

Excitation indices are generated by the existing LAS-UCCSD operator builder.
